# Edu4Migration Website and CMS

## Start here

If you are receiving, reviewing, securing, maintaining, or deploying this project, read [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md) before examining the code or configuring a server.

The handoff explains the complete architecture, frontend and backend behavior, administrator roles, authentication, database, uploaded-file storage, security controls, local setup, production configuration, verified fixes, remaining release blockers, and acceptance tests.

The GitHub Pages version is only a static public preview. A complete deployment requires the React frontend, ASP.NET Core API, SQL Server database, persistent upload storage, and production secrets described in the handoff.
